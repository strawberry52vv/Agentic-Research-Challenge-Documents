# 术语扫盲手册

> 给"不想理解、只想会用"的人：**每一个名词都配一句人话 + 一个比喻。**
> 答辩前只需要读第 1 节（名词）和第 4 节（答辩答案），第 2 节在动手时对照着看。

---

## 0. 一个比喻贯穿全文

把这件事想成**种地**：

| 研究里的东西 | 比喻里是什么 |
|---|---|
| 央行 | **气象台** |
| 货币政策执行报告（MPR） | 气象台每季度发的**天气预报** |
| 报告里的"语气"（宽松/紧缩） | 预报里的**雨量大小** |
| 文本情绪得分 S | 把"雨量"量成**一个数字**（比如 0–10 毫米） |
| 申万一级行业 | **28 块地**（银行、汽车、医药……各一块） |
| 行业收益 | 每块地这一季的**收成** |
| 事件窗 | 暴雨前后那**几天** |
| 面板 | 28 块地 × 约 50 个季度的**收成总账** |
| β̂（行业情绪暴露） | 每块地自己的**吸水系数**（有的地怕旱、有的怕涝） |
| 样本外检验（OOS） | 用前几年的规律去**猜今年的收成**，猜对才算真本事 |

**我们到底在问什么**，用这个比喻就三句话：

1. 预报的"雨量"能不能量得准？（→ 测量问题）
2. 雨大了以后，哪几块地收成涨得多、哪几块不涨？（→ 结构问题）
3. 按"吸水系数"去种地，明年还能不能赚？（→ 可投资问题）

## 1. 必须会说出口的 18 个名词

### 数据类

**① MPR（货币政策执行报告）**
央行每季度发的一份"经济体检报告 + 下一步打算"，官网可下载 PDF。
**比喻**：气象台的季度预报，一年四份，二十年下来一百多份。
**误解**：它不是政策文件本身（不是降准通知），是**解释和表态**。

**② 申万一级行业分类**
把 A 股几千家公司按业务分成 28–31 个大类（银行、汽车、医药……），每类有一个指数。
**比喻**：把一大片地划成 28 块，每块地有自己的"平均收成指数"。
**误解**：2014 年和 2021 年改过两次版（23→28→31 块），**改版前的数据和改版后拼不上**。

**③ 对数收益率**
`r = ln(今天价格 / 昨天价格)`。涨 10% 记作 0.095 左右。
**比喻**：把"涨了几倍"换算成"可以相加的尺子"。今年涨 10%、明年跌 10%，用简单收益率算会差一点，用对数就能直接相加。
**误解**：对数收益**不能跨资产相加**，所以组合收益要换回简单收益（`P_t/P_{t-1}−1`）。

**④ 超额收益 R^ex**
`行业收益 − 大盘收益`。
**比喻**：不看你家收成多少，看**比邻居多收多少**。因为大盘涨的时候所有地都涨，减掉才看得出"是谁的功劳"。

**⑤ 缩尾（Winsorize 1%/99%）**
把最极端的 1% 数值拉到 99% 分位那个值。
**比喻**：一亩地突然收了 100 倍，多半是记错了而不是真丰收，先把极端值"剪平"，免得一个点毁掉整张表。

### 文本类

**⑥ 文本情绪 / 词典法**
拿一张"好词表 / 坏词表"，数一篇文章里好词多还是坏词多。
**比喻**：给每句话贴红蓝标签，"加大力度"贴红、"防范风险"贴蓝，最后数红蓝比例。

**⑦ P 段 / R 段 / F 段**
P（前瞻）= 讲**未来**要干什么（摘要里的展望句 + "下一阶段主要政策思路"）；R（回顾）= 讲**过去**发生了什么（正文各章）；F = 全文。
**比喻**：把预报剪成两半——"未来三天有雨"（P）和"昨天下了 20 毫米"（R）。
**误解**：不分开就会互相稀释。R 段字数是 P 段的 3–4 倍，合起来算平均，前瞻信号就没了。

**⑧ 情感单元法 / 否定词奇偶规则**
不是简单数词，而是逐句找情感词的位置；两个情感词之间出现"不""并非""没有"这类否定词，数它的个数 m：**m 是奇数就翻转情绪（好变坏），是偶数就不翻**。
**比喻**："并非不乐观" = 翻了两次牌子，最后还是乐观；"并不乐观" = 翻一次，变成悲观。

**⑨ z-score（标准化）**
`(分数 − 历史平均) / 标准差`。
**比喻**：不看绝对分，看"在班里排第几"。不同年份用词习惯不同，只有换算成"偏离平均几个标准差"才能比。

**⑩ LLM 打分 / prompt / temperature=0**
让大模型读 P 段，打 1–7 分（1 极度紧缩，7 极度宽松）。prompt 就是你发给它的那段话；temperature=0 表示"每次都给同样的答案，别随机"。
**比喻**：请一位专家按同一张评分表给 102 份报告打分；评分表就是 prompt，温度 0 是"不许拍脑袋"。

**⑪ Spearman ρ（斯皮尔曼相关系数）**
只看**排名**是否一致，不看具体数值差多少，范围 −1 到 1。
**比喻**：你和专家的排名像不像。ρ≥0.7 = 大体一致，可用；<0.7 = 差太多，得改评分表重来。

### 计量类

**⑫ 事件研究 / 事件窗 / CAR**
看某一天（报告发布日）前后几天，行业收益有没有异常。
**比喻**：暴雨那天看哪块地被浇得最狠。`[-1,+1]` = 前一天到后一天，共 3 天。
**误解**：含 −1 不是"修正误差"，而是**检验"消息是不是提前泄露了"**。

**⑬ 面板 / 固定效应（FE）**
面板 = 28 块地 × 50 个季度排成一张长表；固定效应 = 先把"每块地本身的土质差异"（行业 FE）或"同一年所有地共同的大行情"（时间 FE）扣掉，再看雨量的作用。
**比喻**：不比"银行 vs 医药谁收成高"（那是土质差异），只比"同一块地在雨大年和雨小年差多少"。

**⑭ 聚类标准误**
同一块地的 50 个观测不是独立的（今年受去年影响），不能当 50 个独立样本算显著性，要"按行业聚类"。
**比喻**：一个班 50 个学生但只有 5 个老师出题，有效信息量没那么多，不能假装有 50 份独立答卷。

**⑮ HAC / Newey-West 标准误**
允许相邻几期的误差相关（季度报告有惯性）。
**比喻**：承认"上周的天气会影响本周"，算误差时把这点算进去。

**⑯ β̂（行业情绪暴露）**
第 i 个行业对情绪的敏感度，**每季度用截至上一季度的数据重新估一次**（扩张窗）。
**比喻**：每块地自己的吸水系数，而且这个系数每年重算，不许用"全样本一个大系数"（那是偷看答案）。
**前视偏差**：用未来的数据算过去的信号 = 考试偷看答案，结果一定好看但没意义。

**⑰ IC（信息系数）**
每期给 28 个行业按信号排名，看排名和**下一期**涨跌的排名是否一致（Spearman），再取平均。
**比喻**：每次考完预测名次，看猜中多少。IC>0.02 就算有点用。

**⑱ 样本内 / 样本外（IS / OOS）**
前 51 期当"课本"（IS），后 51 期当"考卷"（OOS），考卷不能提前看。
**比喻**：课本上做熟的题不算本事，高考卷上做对才算。
**误解**：只报 IS 高分是**学术不诚实**，必须两条线都画。

## 2. 十二步操作，每步一句比喻 + 一个"做错会怎样"

| 步 | 我们在干什么 | 相当于 | 做错会怎样 |
|---|---|---|---|
| 1 | 下载 102 期 PDF | 把二十年的天气预报全复印回来，按季度编号放好 | 期数缺了没记 → 后面所有表都少行，且查不出来 |
| 2 | 记发布日 | 记清每份预报是**哪天贴出来的**（不是它讲的那个季度） | 用报告期当发布日 → 事件窗全错位，结论作废 |
| 3 | 切 P/R 段 | 把"未来三天有雨"和"昨天下了 20 毫米"剪开 | 不切 → 前瞻信号被回顾内容稀释到接近 0 |
| 4 | 分词 + 词典 | 给每句话贴红蓝标签，数红蓝比例 | 词表里没"降准""逆周期" → 关键词被切碎，分数失真 |
| 5 | 否定规则 | "并非不乐观"要翻两次牌子 | 不处理 → "防范风险"被当成坏词，方向反了 |
| 6 | z-score | 把绝对分换成"在班里排第几" | 不标准化 → 早年用词客气、近年直白，趋势是假的 |
| 7 | LLM 打 102 次分 | 请专家按同一评分表打一遍，当"第二个裁判" | 不固定 prompt/温度 → 每次分数不一样，复现不了 |
| 8 | 效度图 F1 | 把情绪曲线和五次大事件摆一起看方向 | 方向反了还硬跑回归 → 后面全白干（先查词典，别调样本） |
| 9 | 拼面板 | 把 28 块地 × 50 季的收成排成一张总账 | 键没对齐（行业代码 vs 名称）→ 拼出空表 |
| 10 | 时序回归（H1） | 全国平均收成 vs 雨量（一条时间线） | 把报告级变量塞进面板 → 系数根本估不出来 |
| 11 | 面板交互（H2） | 哪类地（怕旱的）对雨更敏感 | 忘了加时间 FE → 估出来的是"大行情"，不是雨量 |
| 12 | β̂ + 组合（H2′/H4） | 按每块地的吸水系数，买最该涨的 5 块地，再用考卷验证 | 用全样本估计 β̂ → 前视偏差，OOS 一定崩 |

## 3. 三个公式，一句话翻译

**① 时序：** `R^ex_t = α + β₁·S⁺_t + β₂·S⁻_t + 控制 + ε`
> 行业平均超额收益 = 常数 + **宽松时的反应** + **紧缩时的反应** + 其他因素。看 β₂ 是否显著为负。

**② 面板：** `R^ex_{i,t} = α + δ·S_{t−1}×Char_i + θ·Char_i + μ_i + λ_t + ε`
> 第 i 个行业在 t 季的超额收益，取决于"上季雨量 × 这块地的特征"。**只看 δ**：特征越强，雨的影响越大。
> 注意：只有"交互项"能这么估，单独看 S 的作用估不出来。

**③ 信号：** `Signal_{i,t} = β̂_{i,t} × S_t`
> 这块地的"吸水系数"乘以"这季的雨量" = 这季该买多少。按这个数排序，买前 5 卖后 5。

## 4. 答辩怎么说（照抄，改成你自己的话）

**必答三问**（规划书 §10 已经写死，一人背一问）

| 评委问 | 你答（大白话版） |
|---|---|
| "情绪是报告级变量，怎么做行业面板？"（**乙答**） | "这份报告只有一份，28 个行业拿到的是同一个情绪分，所以'情绪本身的影响'只能在时间上看；面板里能看的只有'行业之间的差异'，也就是情绪 × 行业特征那一项。这是设计上的取舍，不是遗漏。" |
| "这不就是姜富伟换个被解释变量？"（**丙答**） | "姜老师看的是大盘和发布后一天的反应；我们多做的是**每块地自己的吸水系数**——把它估出来，并且在没看过的后 51 期上检验能不能用。这一条前面没有人做。" |
| "情绪会不会只是降准降息的影子？"（**甲答**） | "我们专门加了一列：把降准降息、逆回购利率变动、CPI、PMI 都控制住，再看情绪还剩多少。**剩多少都照实报**；如果被吃光，那本身就是结论——文本情绪是政策周期的影子。" |

**五个可能的追问**

| 追问 | 答 |
|---|---|
| "为什么只有 1400 个观测？" | "受行业分类两次改版限制，28 个行业的干净区间从 2014 年开始。**我们的识别优势来自行业之间的差异，不来自样本长度。** 早期 102 期用在市场层和事件研究上。" |
| "为什么样本外可能失效？" | "我们主动切了一半当考卷。失效也会照实报衰减幅度——这比只报好看的样本内可信。" |
| "词典打分靠谱吗？" | "三套词典互相对照，再让大模型独立打一遍，一致性到 0.7 以上才用；并且五个宏观转折点方向都对得上。" |
| "为什么不显著也算成果？" | "我们要回答的是'有没有结构差异'，答案可能是'没有'——那就是'央行书面沟通是总量工具'，这个结论有政策含义。" |
| "AI 干了多少？" | 翻 `5_AI使用记录`：哪一步用了什么模型、AI 初稿占比、人改了什么。**"人改了什么"这一列才是重点。** |

## 5. 八组最容易搞混的词

| 容易混 | 区别（一句话） |
|---|---|
| 情绪 vs 情感 | 这里都指"语气倾向"（松/紧），不是人的感情 |
| 显著 vs 有效 | 显著 = 不太可能是巧合；有效 = 真能赚钱。两回事 |
| 相关 vs 因果 | 我们只做"预测性"分析，**不说因果** |
| 样本内 vs 样本外 | 课本 vs 考卷，考卷不能提前看 |
| 不显著 vs 失败 | 不显著是"没找到证据"，照实报就是合格；为显著改样本才是真失败 |
| 回顾段 vs 前瞻段 | 讲过去 vs 讲未来；我们只用前瞻段当主变量 |
| 行业 FE vs 时间 FE | 扣掉"地本身的差异" vs 扣掉"当年大行情" |
| 对数收益 vs 简单收益 | 算敏感性用对数；组合相加必须用简单收益 |
