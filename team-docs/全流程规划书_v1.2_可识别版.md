## 1. 选题定位（重写口径）

### 1.1 研究问题（三问，取代 v1.1 的"预测力"一问）

- **Q-A（测量）**：MPR 的**前瞻段情绪**能否被稳定度量，且与宏观事件轨迹对得上？
- **Q-B（结构）**：同一份报告的情绪，在 28 个申万一级行业上是否产生**可被行业特征解释的差异**？若无差异，说明央行书面沟通是**总量性工具**。
- **Q-C（增量与可投资）**：控制当期实际政策操作与宏观状态后，情绪是否仍有增量？由之构造的**行业情绪暴露信号**在样本外是否具备配置价值？

> 这一改写的意义：Q-B 与 Q-C 的正负结论**都有政策含义**——"总量信号、无结构信号"本身就是一个有分量的负结果（可直接反驳"政策文本可做行业轮动信号"的流行叙事）。v1.1 只有"预测力"一问，一旦不显著就只剩"没做出来"。

### 1.2 假设（修完文献依据再上）

| 编号 | 假设 | 检验位置 | 文献依据（已核原文） |
|---|---|---|---|
| **H1** | **非对称**：情绪转紧缩对行业（等权）超额收益的负向效应**更即时**；转宽松的正向效应**更持久但当期较弱** | §4.3 时序回归（M2b） | 林雨欣（2025）"宽松影响更持久、紧缩短期更显著"；王宇伟等（2025）"紧缩打击信心、宽松提振有限"（**对象为企业家信心，仅作机制类比**） |
| **H2** | 行业敏感度由**融资成本敏感性、需求弹性、政策依赖度、估值水平**决定；前三项高、估值高的行业更敏感 | §4.4 面板交互（M2a） | 林雨欣（2025）前三项（**逐字重合，本版明确标注为"沿用并扩展"**）；游庭玮（2026）估值调节 |
| **H2′** | **行业情绪暴露 β̂_i 本身可估且稳定**：扩张窗估计的 β̂_i 在样本外仍能区分行业 | §4.5 组合 OOS | 本研究新增（这是唯一的"新测量"贡献） |

### 2.3 收益与对齐

- 行业收益：`r = ln(P_t/P_{t-1})`（日），季度按**发布日对齐**（发布日→下一发布日），并**同时保留**日历季度口径做稳健性。
- **组合层面的收益必须换回简单收益**（`P_t/P_{t-1} − 1`）：对数收益跨资产不可加，v1.1 的"多头等权 − 空头等权"在对数口径下是错的。
- 事件窗：交易日累积，窗口 `[-1,+1]`、`[-1,+3]`、`[0,+5]`、`[0,+10]`。
- **发布时刻**：若为收盘后发布，事件日顺延至下一交易日；逐期尽量记录发布时间。
- 缩尾 1%/99%，缺失不插值（新设行业缺失如实标注）。

## 3. 文本指标（保留 v1.1 的算法，改判据与用途）

### 3.1 分段（P/R/F）

| 段 | 范围 | 性质 | 用途 |
|---|---|---|---|
| P（前瞻） | 摘要 + "下一阶段主要政策思路" | 政策立场、未来取向 | **主解释变量** S_t |
| R（回顾） | 正文各章节 | 历史状态 | 对照组，预期不显著 |
| F（全文） | 全篇 | 合并 | 稳健性 |

注意：MPR 的"摘要"本身包含对上一期的回顾，严格意义上 P 段 = 摘要中的展望句 + "下一阶段主要政策思路"章。**切分时以章节标题为锚，不按页数切**，10 期人工抽检≥9 期正确。

### 3.2 词典与算法（不变，但加"可得性前置"）

- 主词典：中文金融情感词典（姜富伟等）+ 政策词补充（汪禹、吴彬 2025）；对照：Hownet。
- 情感单元法：jieba 注入自定义词典 → 分句 → 标记情感词位置 → 否定词奇偶规则（m_i 奇则乘 −1）→ 句内加权 → 段内平均 → z-score。
- **公式改一处**：`Sentiment = (Pos − Neg)/(Pos + Neg + κ)` 中 κ=1 的平滑在 P 段（短文本、低命中）会造成离散跳变，改为**每千字强度** `(Pos − Neg)/字数×1000`，并保留比值口径做稳健性。
- **拆分改一处**：`S⁺ = max(S_z, 0)`、`S⁻ = min(S_z, 0)`（在标准化分上取正负，保留幅度），不用"按符号二分后重建"。

**前置动作（Day 0，2 小时）**：确认两套词典能否拿到词表。拿不到 → 立即改为"自建词表（种子词 + word2vec 扩充 + 人工补政策词）"，并在数据说明写"自建"，词表版本号 `dict-v1`。**不要写"沿用姜富伟词典"却实际用了自建表**——这是诚信问题。

### 3.3 LLM 标注（102 次，全 P 段，不再叫"抽样"）

- 1 个维度：政策立场 1–7；temperature=0；固定 model id 与日期；结果缓存；prompt 版本号。
- 人工校验 20 期（≈20%），算 Spearman：
  - ρ≥0.7 → 视为**一致**，用于交叉验证；
  - ρ<0.7 → 调 prompt 重标，仍<0.7 → **在论文中报告"LLM 与人工不一致"，并把 LLM 只作描述性证据**。
- **用途收窄**：只做 §5.5 的一致性检验与 F1 叠加散点，**不进入主回归，不做优劣推断**。

### 3.4 效度第一检验（F1）

情绪轨迹 vs 宏观事件（保留 v1.1 的表）：2001 入世→2007 上升；2007→2009 下滑；四万亿后回升；2015 股灾下滑；2020 疫情下滑后回升。
判据：**5 个转折点方向一致才算指标可用**；不一致先改分词与词典，不改样本。

## 4. 实证设计（**本版核心**）

### 4.1 三个估计对象，各配一套设计（不许混用）

| 对象 | 变异来源 | 设计 | 能回答 | 不能回答 |
|---|---|---|---|---|
| E1 报告级信号的市场层效应 | 纯时间 | 时序回归（行业等权超额收益） | H1、H5 | 行业差异 |
| E2 行业层差异效应 | 行业 × 时间（交互） | 面板 + 交互项（含时间 FE） | H2 | S 的主效应 |
| E3 行业暴露信号 | 行业（β̂_i）× 时间（S_t） | 扩张窗估计 + OOS 组合 | H2′、H4 | 因果 |

> 一句话：**S 是报告级的，所以"S 的主效应"只能在时间维上估；行业维上能估的只有"差异"。**这是 v1.1 全部设计错误的根源，也是本版所有改动的出发点。

### 4.2 事件研究（E2 的横截面证据）

| 要素 | 设定 |
|---|---|
| 事件日 | MPR 发布日（收盘后发布则顺延 t+1） |
| 估计窗 | 事件前 120 个交易日 |
| 正常收益 | 市场模型；2001–2005 基准＝上证综指，2005 后＝沪深300（主），上证综指为稳健 |
| 事件窗 | `[-1,+1]`、`[-1,+3]`、`[0,+5]`、`[0,+10]` |
| 检验 | **按事件日聚合成行业组后检验**（或时间聚类），不逐行业 t 检验；辅以符号检验、按事件日 bootstrap |

**横截面设定**：
```
CAR_{i,e} = a + b·S_e × Char_i + c·Char_i + d·S_e + μ_i + e
```
- `S_e × Char_i` 的系数 b 即"H2 在事件窗内的版本"，**可识别**（行业×事件变异）。
- 分组比较：按 S 高低分两组，比组内 CAR 的行业排序是否一致。
- **必须排除同日发布的 CPI/金融数据事件**（或加同日哑变量），否则事件窗被宏观数据污染。

> **注（改写 v1.1 的论证）**：含 −1 的理由是"检验预漂移是否存在"，而不是"修正 CAR 低估"。王春芝（2022）的结论是预漂移源自**不确定性缓解**，与公告内容的宽松/紧缩**无关**——所以 −1 窗只能用于检验"信息是否提前泄露/预期已定价"，不能宣称预漂移携带情绪信息。`[0,+5]`、`[0,+10]` 保留作对照，正文按"含 −1 与不含 −1 的差 = 预漂移部分"来解释。

### 4.3 时序回归（H1 的唯一检验场）

**被解释变量**：行业**等权**超额收益序列 `R^ex_t = mean_i(R_{i,t}) − R_{m,t}`（市场调整，避免与 S 共线于趋势）。

```
R^ex_t = α + β₁·S⁺_t + β₂·S⁻_t + γ·Controls_t + ε_t
```
- 标准误：**HAC（Newey-West，滞后 2 期）**；样本 102 期。
- 控制变量：市场波动、政策操作（降准降息哑变量、7 天逆回购利率变动）、CPI/PMI、季度哑变量（可选）。
- **判据**：β₂ 显著为负（p<0.1）→ 紧缩端成立；β₁ 不显著或弱 → 与林雨欣"宽松更持久"互补，需讨论"即时 vs 持久"的差异。
- **增量检验（必做，评委必问）**：
```
R^ex_t = α + β_S·S_t + β_P·PolicyAction_t + γ·Macro_t + ε_t
```
  报"加入政策操作后 S 的系数变化"。**若 S 的系数被吃掉，这就是本文最有价值的结论之一**（"文本情绪是政策周期的影子"），不要藏。

### 4.4 面板交互（H2）

```
R^ex_{i,t} = α + δ·S_{t-1} × Char_i + θ·Char_i + μ_i + λ_t + ε_{i,t}
```
| 要素 | 设定 |
|---|---|
| 面板 | 28 行业 × ≈50 季 ≈1400 观测（非平衡） |
| 被解释变量 | 市场调整超额收益（主）；事件窗 CAR（辅） |
| 固定效应 | 行业 FE + **时间 FE**（此时只有交互项可识别，正是本设计要的） |
| 标准误 | 行业维度聚类（28 簇）；辅以"事件/时间双向聚类" |
| 特征 | 融资成本敏感性＝财务费用率/资产负债率；需求弹性＝周期属性哑变量（可选消费/耐用消费）；政策依赖度＝MPR 中该行业相关表述频率；估值＝PE/PB 分位 |
| 预期符号 | δ>0（特征越强，情绪效应越大） |

**注意三点**：
1. Char_i 若为时不变，会被行业 FE 吸收 → 必须用**时变版本**（滚动 3 年分位、季度 PE/PB）。
2. 政策依赖度用"MPR 提及频率"时，需**剔除当期报告本身**（用 t−1 期及之前的提及频率），否则内生。
3. 分组回归（高低组比 β）与交互项互为稳健性，报一处、另一处进附录。

### 4.5 行业暴露信号与组合（H2′、H4）

**第一步：估 β̂_i（扩张窗，严禁全样本）**
```
R^ex_{i,τ} = a_i + b_i·S_{τ-1} + ε        τ ∈ [1, t-1]，最少 20 期起估
```
每季度用**截至 t−1 的信息**重估 b_i，得 β̂_{i,t}。全样本 β̂ 是前视偏差，绝不能用。

**第二步：信号**
```
Signal_{i,t} = β̂_{i,t} × S_t
```
- 这是行业级信号（β̂ 有行业差异），可以排序 → **A2 的缺陷在此消除**。
- 横截面 IC 由此可计算：每期 `IC_t = Spearman(Signal_{i,t}, R^ex_{i,t+1})`，报均值、t 值、胜率。

**第三步：组合（OOS）**
- **样本切分**：前 51 期估计/训练，**后 51 期只做检验**（或扩张窗 + 逐期 OOS）。
- 每期多前 5 / 空后 5（28 行业中约各 18%），季度调仓，**等权、简单收益**。
- 基准：行业等权组合 + 沪深300。
- 报四项：年化收益、年化波动、夏普、最大回撤；另报**样本内/样本外对比**（这是诚实的关键）。
- Alpha：`R_p = α + β·R_mkt + ε`（HAC），**不强行上 FF3/SMB/HML**（A 股需 CH-3/CH-4，构造成本高，7 天内不做）。
- **交易成本**：按单边 0.1% 计一版，报"含成本"结果。

### 4.6 稳健性（核心三项 + 可选两项）

| # | 检验 | 做法 | 目的 |
|---|---|---|---|
| 1 | 三套词典 + LLM 一致性 | 姜富伟/政策词典/Hownet 的 S 相关矩阵；LLM ρ | 测度稳健 |
| 2 | 事件窗与基准 | 4 个窗 + 沪深300/上证综指 | 结论不靠某个窗 |
| 3 | 子样本 | 2008 前/后、2015 股灾、2020 疫情、剔除金融 | 不是某时期特有 |
| 4（可选） | 换行业口径 | 31 行业（2021 起）重算 H2 | 口径稳健 |
| 5（可选） | 换频率/滞后 | 月度（S 前推）、滞后 2 期 | 时点稳健 |
